# 微信 AI 桌宠

[下载 Windows 安装包](https://github.com/boshihaihai/wechat-ai-pet/releases/latest) · [反馈问题](https://github.com/boshihaihai/wechat-ai-pet/issues)

为当前打开的微信聊天生成回复草稿。私聊自动推荐，群聊单击宠物生成；按 **Tab** 填入完整内容，发送由你决定。程序不使用 OCR，也没有自动发送功能。

当前版本为个人使用版 0.7.0。每次构建的时间和文件指纹记录在 `release/build-info.json`，同名安装包以该记录区分。本项目尚未完成长期运行、多屏和所有输入法组合的发布验收，不宣称通过苹果或其他公司的产品认证。

## 使用

1. 运行 `dist/WeChatPet-Setup-0.7.0.exe`。更新前保存设置并从托盘退出桌宠；安装和卸载保留个人配置与记忆。
2. 打开宠物的“模型连接”，选择服务并完成连接与验证。支持 ChatGPT 账号、DeepSeek 账号或 DeepSeek API，实际模型以服务返回为准。
3. 打开微信聊天，保持输入框为空。私聊的新来信、重新打开的未回复聊天会触发推荐；群聊需要单击宠物。
4. 在微信空输入框按真实键盘 Tab，推荐变为未发送草稿。已有草稿或正在中文组词时不会覆盖输入。

关闭宠物窗口会隐藏到托盘，右键可退出。隐藏宠物时，推荐以单行灰字显示在微信输入框。长回复只在确有省略时显示“查看全文”，展开区域可滚动；Tab 始终采用完整原文，推荐有效期为 60 秒。

## 能做什么

| 场景 | 行为 |
|---|---|
| 当前私聊收到文字或可读取的自带表情 | 结合当前话题和这位好友的设定生成推荐 |
| 当前群聊 | 单击宠物生成，按账号和群隔离偏好与约定 |
| 切换好友、账号或输入内容 | 撤销旧推荐，拒绝迟到结果，防止串用 |
| 微信被其他窗口遮挡但未最小化 | 可继续读取；采用时需返回微信输入框 |
| 微信最小化、账号身份不明 | 暂停读取或采用；未实现可靠的新消息提醒 |
| 图片、语音、贴纸等未知尾消息 | 不凭类型猜测内容，不对前一条文字继续生成 |
| 多位好友同时来信 | 只处理当前打开的聊天，不遍历全部会话 |
| 模型或存储失败 | 显示原因，不自动切换服务、不盲目重复填入 |

表情预览使用已核实的微信表情原图。含已核实名称的回复通过临时剪贴板和受保护的粘贴转换，并核对完整草稿；纯文字沿用输入框接口。未开始粘贴时可恢复原剪贴板，已调用但结果不明时会停止并提示，不覆盖用户后来复制的内容。未知名称保留文字。

## 记忆

记忆按**微信账号 + 稳定好友/群标识**区分，不依靠昵称。账号尚未确认时不显示其他账号的资料。记忆页提供好友/群分类、搜索、当前聊天定位和删除入口。

- **好友设定**：你手动填写的关系、背景和回复方式，最多 400 字符；可以选风格后补充描述。
- **表达示例**：你手动选定的说话方式，最多 5 条、每条 200 字符。
- **好友偏好**：从对方的明确自述中按有限规则自动提取，保留来源。最新明确表达替代冲突旧表达；提问、临时状态、推测和复杂句不当作长期事实。
- **近期聊天**：保留当前打开私聊实际读到的摘录，最多 30 条、通常保留 7 天；自动明确偏好最多 20 条、通常保留 30 天；手动或固定内容最多 30 条，直到修改或删除。
- **群聊记忆**：每群独立保存回复偏好和群内约定，手动维护，不把群成员发言学进私聊资料。

推荐和未发送草稿不进入自动记忆。关闭某位好友的记忆后停止学习和使用其资料。删除后设有时间截止点，旧消息不会立刻把已删记录恢复。旧版无归属备注需由用户明确确认，不能复制给所有人。好友和群集合各有 500 个档案上限，跨账号合计；达到上限时会提示清理，已有资料继续可用。存储文件上限 16 MiB。

记忆、模型配置与凭证保存在当前 Windows 用户的本地应用数据目录；凭证和记忆使用 DPAPI 加密。保存失败会保留原值和编辑内容，读取损坏时保留文件并暂停使用，不用空数据覆盖。模型请求只附当前会话的受限上下文和对应记忆；使用模型服务时，这部分内容会传给所选服务。

## 构建与验证

需要 Windows x64、.NET Framework 4.x 的编译器/WPF，以及已验证的 Node.js v24.14.1。全部宠物、图标和表情素材都在项目内的 `assets/wechat-pet/`，构建、测试和打包不依赖项目外的素材目录。整个项目可以单独复制、改名或搬移；源码包也只包含这一个完整项目文件夹。

构建优先使用项目已有的 `release/runtime/node.exe`；没有运行产物的干净源码会从 `PATH` 查找 Node.js，也可使用 `Build.ps1 -NodePath '你的路径/node.exe'`（安装包脚本同样支持）。不要求 Node.js 安装在固定目录，Windows 编译器位置从系统目录获取。源码包不重复携带 Node.js 二进制，首次构建需准备上述工具。

搬移后可直接运行 `release/WeChatPet.exe`，请一起保留整个 `release` 目录；运行不依赖工作目录、源码目录或系统安装的 Node.js。同一 Windows 用户下搬移会继续使用 `%LOCALAPPDATA%/WeChatPet` 中的配置和记忆。换电脑或 Windows 用户时，DPAPI 加密的个人数据不能直接复制使用，需要重新连接模型。微信功能仍需要受支持的微信版本和已登录会话。

`tests/native-emoji-extraction/extract-classic.py` 仅用于重新溯源表情素材，运行时需显式传入已核实的 `Weixin.dll` 路径并准备其 Python 依赖；普通构建和运行不调用它，也不需要原微信安装目录。路径应避免过深，现有 .NET Framework 工具及测试仍受 Windows 传统路径长度限制。

```powershell
.\Build.ps1 -Test
.\Build.ps1 -Preview
.\Package.ps1 -SkipBuild
.\Package-Source.ps1
```

`-Test` 执行合成会话、记忆隔离、失败恢复、表情、全文、界面和安装器检查；模型集成使用替代网络实现，不请求真实服务。测试程序集与正式程序分开编译，临时测试程序运行后清理。`-Preview` 只渲染合成界面。正式程序只接受真实键盘 Tab 采用推荐，不保留旧注入按键测试版。

安装包只含运行程序、固定运行时、资源、许可证及使用说明。源码包只含维护中的源码、回归测试和必要溯源资料，不含实聊记录、凭证、旧探针、临时截图或历史安装日志。当前审查结果与删除清单保存在本地 `reports/`，不随产品分发。

## 尚待完成

当前原生适配仅允许已校验的微信 4.1.15.13 构建；微信更新后可能停止读取，需要重新验证。UIA 同步调用没有逐调用硬中断保证。最小化提醒、微信原图自动获取尚未可靠实现。安装器能处理可捕获异常回滚与并发互斥，但断电或被强制终止后的事务恢复仍需完善。

发布前还需补齐真实中文输入法与实体 Tab 的组合、多屏 DPI、至少 60 分钟持续运行和实际卸载验收。程序尚未签名，素材公开分发授权也需另外核实。当前自动检查不能替代这些验收。
